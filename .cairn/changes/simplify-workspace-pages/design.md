## Context

Each page shares one title and one canonical destination description. Page content can still repeat that description or lead with lower-priority context.

## Decisions

### Decision: Put tasks and current state first

**Choice:** Keep purpose copy concise, prioritize failures and execution targets, and give supplemental context an explicit disclosure where helpful.

**Rationale:** Operators see what needs action without losing access to exact identifiers, evidence, or the full set of routes and controls.

## Risks / Trade-offs

- Do not collapse active blockers, confirmations, failure state, or authorization boundaries merely to reduce visual density.
