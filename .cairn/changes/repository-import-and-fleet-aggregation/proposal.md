## Why

Repositories in Kiln currently have to be hand-registered separately across `service.json`, `sources.json`, `code-review.json`, and Clan `modules/kiln-fleet/lib.nix`, and there is no unified way in the Factory Control Plane to import repositories from GitHub, Gitea/Forgejo, or Radicle as canonical remotes or mirrors, nor to see all local working copies of each repository aggregated across fleet machines (`britton-desktop`, `aspen3`, `aspen1`, etc.) with their VCS (`git`, `jj`, `pijul`), HEAD revision, dirty state, drift, and active Cairn counts.

## What Changes

- Add a pure `no_std + alloc` repository catalog & fleet-copy aggregation core in `crates/kiln-core/src/repository_catalog.rs` that assigns BLAKE3 canonical Kiln identities (never replaced by provider IDs), validates and normalizes GitHub, Gitea/Forgejo, and Radicle remote/mirror endpoints (`canonical` vs `mirror`), matches observed local working copies across fleet machines by normalized remote identities, and computes honest sync/drift states (`synced`, `diverged`, `dirty`, `unknown`, `local_only`) within named bounds.
- Add read-only Fleet local-copy census (`GET /v1/repositories` in `crates/kiln-fleet`) inspecting configured repository roots and agent hosts without mutating working trees, reporting `Unavailable` explicitly when a host is offline, and proxy `GET /api/fleet/repositories` through `crates/kiln-web-service/src/fleet.rs` (with `authority_coverage` entry point registration).
- Add durable, operator-guarded repository import and catalog APIs in `crates/kiln-web-service` (`GET /api/repositories`, `POST /api/repositories/import`, `POST /api/repositories/{id}/mirrors`, `POST /api/repositories/{id}/remove`, `POST /api/repositories/refresh`) merging imported remotes/mirrors, configured CI projects/sources, local coordinator checkouts, and Fleet local copies, strictly enforcing read-only Radicle discipline (zero Radicle initialization, signing, push, or mirror publication) and `request_id` idempotency.
- Add a first-class **Repositories & Fleet Copies** view in `3.2 System & Source` (linked from `1.1 Factory`, Slide-Over `?inspect=repo:<id>`, and `Ctrl+K` `> import repo`) with an Import Repository / Add Mirror flow for GitHub, Gitea/Forgejo, and Radicle (`canonical` vs `mirror`), per-machine local-copy breakdown, drift/dirty/offline badges, and active Cairn counts.

## Impact

- **Files**: `crates/kiln-core/src/{repository_catalog.rs,lib.rs,implementation/authority/entry_points.rs}`, `crates/kiln-fleet/src/{api.rs,repositories.rs,lib.rs}`, `crates/kiln-web-service/src/{repository_catalog.rs,fleet.rs,lib.rs,main.rs,server.rs,source.js,source.css,web.html,web.js,web.css,work-interaction.js}`, `docs/console-port-inventory.json`, `crates/kiln-web-service/tests/repository_import.rs`, `tests/repository-import-ui.test.mjs`.
- **Testing**: `cargo test --locked -p onix-kiln-core -p kiln-fleet -p kiln-web-service`, `cargo test --locked -p kiln-implementer --test authority_coverage`, `node --test tests/*.test.mjs`, and `cairn validate --root . --strict` covering positive and negative cases (malformed URLs/RIDs, embedded credentials, duplicate canonicals, offline hosts, unauthorized imports, stale/conflicting `request_id`, and Radicle non-mutation).
