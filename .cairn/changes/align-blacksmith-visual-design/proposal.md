## Why

The operator requests Blacksmith's visual character for the live Kiln dashboard. The existing rounded olive workspace does not match the reference's charcoal/off-white palette, acid-yellow emphasis, square framed panels, monospaced labels and compact console navigation.

- Restyle the live shell, navigation, controls, metrics, work lists and dialogs as one consistent industrial console.
- Preserve Kiln branding, light/dark/system appearance, compact density, mobile touch targets, keyboard focus and every existing route and authority boundary.
- Use local CSS and decorative inline SVG only; do not add remote fonts, tracking, assets, fake metrics or provider dependencies.

## Impact

Current consumers are authenticated Kiln developers and CI operators. Kiln web-service/dashboard maintainers own the visual system. Durable contribution: a coherent reusable live-console presentation over existing CI and work views. Existing offline catalog rendering remains unchanged. Verification uses actual desktop/mobile browser views, appearance switching, real retained CI data and applicable repository checks.
