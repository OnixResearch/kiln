## Page audit

| Page | Default task and decision |
| --- | --- |
| Overview | Triage failures. Put attention first; unresolved runs precede recent passes. |
| Runs | Find and inspect an exact run. Keep the existing split view, status and filter controls. |
| CI projects | Find a project before starting a run. Keep inventory before operator forms. |
| CI project detail | Check one project's recorded history. Keep its exact route and retained coverage. |
| Workers | Choose an execution target. Put the target register or exact target detail before resource observations. |
| Runbooks | Choose a reviewed procedure and its allowed target. Keep the typed form and its constraints together. |
| Issues | Find or file a record. Keep the existing result list and detail pairing. |
| My inbox | Review assignments and mentions. State that opening does not mark an item read. |
| Planning | Organize issues. Name the four planning dimensions directly. |
| Code review | Check what blocks exact-revision submission. Keep the CI-versus-merge boundary visible. |
| Requests & triage | Decide what to take on. Keep original request identity and source. |
| Saved views | Reopen a saved filter or board. Remove the catalog-like introduction. |
| Cairn changes | Find the next step. Keep lane statuses, blockers and the authority boundary. |
| Fleet | Address decisions and expiring claims first. Keep machines, attempts and claims ahead of supporting observations. |
| Source | Choose a repository and revision. Keep the separate disclosure for provider-specific read boundaries. |
| Patchgate receipts | Read the verdict and why. Keep the distinction between evidence and acceptance. |
| Activity | Trace what happened. Shorten the heading to Timeline; keep audit and events distinct. |
| Feeds | Follow CI or external feeds. State the non-evidence boundary once. |
| Evidence | Choose a retained run. Keep the exact ID field and visible scope of suggestions. |
| Automation | Check trigger and delivery status. Keep the ambiguous-delivery warning. |
| Operations | Check capacity, queue and retention. State that warnings do not prune state once. |
| Raw collaboration history | Search stored operations. Keep an explicit distinction from reduced lifecycle state. |
| Settings | Check access or change appearance. Keep credential and authorization boundaries. |
| Guide | Look up a destination, status or shortcut. Keep the numbered lookup as the complete index. |
