## Decisions

The trusted controller loads a content-addressed frozen profile outside the editing worker workspace. The bounded-exec process mechanism executes exact absolute argv with a cleared frozen environment. Git independently resolves exact commits/trees and complete NUL-delimited changed paths from an enrolled local repository; no worker-provided success JSON is accepted. A fresh detached snapshot is used per check and baseline, and immutable verifier programs are hash-checked. Required nonempty artifact bytes are retained and hashed by the controller. Protected policy, acceptance and verifier paths cannot change or disappear; `.cairn` defaults to baseline equality, with only an exact independently prepared lifecycle tree frozen in the profile admitted before review. Baseline/candidate bug checks use the same frozen command and environment.

Cairn completion remains its existing evaluate_authoritative_agent_completion evaluator. The adapter builds AgentExecutionResult from retained trusted observations, preserving exact work aliases and source versions in the outer receipt. Canonical CiFact/CiCheck receives only independently executed evidence. Existing ledger and review queue remain authority owners.

The acquisition bridge independently recomputes Lattice native byte-snapshot tree/diff identities from the exact Git baseline and actual retained host workspace, then materializes a deterministic Git tree/commit without worker metadata. Explicit native unchanged observations require both no-change policies and resolve to the exact baseline commit. The canonical Engine consumer records ordinary events/observations/artifacts, retains checked native-source-to-repository-alias provenance, and excludes protected verifier records from provider polling/recovery/retries/controls. No second CI success store or postreview source lifecycle mutation is introduced.

## Verification

Positive bug and feature fixtures paired with refusal cases for forged/missing artifacts, stale envelopes, incomplete paths, changed protected definitions, unknown process outcomes and unauthorized no-change. Parent runs focused tests after integration; no live pilot is claimed.

## Non-claims

This local verifier is not a hostile sandbox. Admission requires an operator-owned execution identity and snapshot area inaccessible to the worker. Real pilot requires that host separation, frozen verifier programs/toolchain and operator-selected bug/feature repositories.
