## Why

Even after P0 safety and reconciliation fixes, Kiln's console still fragments operator attention across 23 rail destinations, 4+ disconnected inboxes, a 9-panel vertical scroll in Fleet, 1.5s pseudo-SSE short-polling in CI alongside per-tab upstream polling loops against `kiln-fleet`, a `Ctrl+K` palette blind to Fleet/Cairn/Campaigns/Workers, a flat merge queue list, and zero browser access to live `herdr` agent panes or host slot occupancy—even though `kiln-core/src/fleet/session.rs` explicitly instructs operators to read blocked agent panes and answer their questions.

P1 transforms Kiln into a cohesive Software Factory Control Plane: 7 authoritative top-level destinations, a 2-region Factory Cockpit + `44rem` Slide-Over Inspector with live `herdr` panes and unified escalations, one multiplexed `/api/events` SSE stream backed by a single coordinator watcher, full-factory `Ctrl+K` with typed operational verbs and Tier 1–3 safety rails, and a 3-pane Code Review workbench with inline anchored threads, interactive `jj` stack rail, and visual Speculative Merge Train.

## What Changes

- Consolidate the 23-link navigation rail into **7 primary destinations across 3 groups + footer** (`1.1 Factory`, `1.2 Attention`, `2.1 Delivery & Cairn`, `2.2 Runs & Evidence`, `2.3 Code Review & Queue`, `3.1 Fleet & Workers`, `3.2 System & Source`, plus `0.0 Guide` and `4.4 Settings`), updating `docs/console-port-inventory.json`, `web.html`, `ui.js`, and `tests/live-console-ui.test.mjs` in lockstep while preserving legacy `?page=` query aliases and adding `?inspect=<kind>:<id>` drawer deep-links.
- Build the flagship **2-region Factory Cockpit + `44rem` Slide-Over Inspector** inside `.page-frame-wide` (`110rem`): persistent Global Live Strip, Live Telemetry Ribbon, auto-collapsing **Unified Attention & Escalation Inbox** (`GET /api/implementation/attention`), compact live **Delivery Spine** rows + Speculative Merge Train strip, **Machine & Slot Census** (`GET /v1/machines`), Expiring/Foreign Claims & Budget rail, inline `plan_not_accepted` plan-step gate, and visible-only live `herdr` pane tailing + steer/interrupt controls.
- Expose missing `kiln-fleet` control-plane routes (`GET /v1/machines`, `POST /v1/machines/{name}/drain`, `GET /v1/attempts/{id}/pane?lines=200`, `POST /v1/attempts/{id}/prompt`, `POST /v1/attempts/{id}/interrupt`, `GET /v1/claims?include=foreign,expired`, `GET /v1/dispatch/status`, `POST /v1/dispatch/pause|resume`) and proxy them through `crates/kiln-web-service/src/fleet.rs`.
- Add `GET /api/implementation/attention`, `POST /api/implementation/campaigns/{id}/wake`, and `POST /api/implementation/reconcile-termination` so blocked campaigns and ambiguous terminations can be resolved directly from Attention and the Slide-Over Inspector.
- Unify CI `/api/live` (currently 1.5s short-polling) and `/api/fleet/events` into **one multiplexed SSE stream per tab (`/api/events`)** backed by a **single shared background coordinator watcher** in `kiln-web-service`, protecting `kiln-web-service`'s thread-per-connection limit and `kiln-fleet`'s `MAX_CONNECTIONS = 32` socket pool.
- Upgrade `Ctrl/Cmd+K` (`work-interaction.js`) to index Fleet claims, attempts, decisions, Cairn changes, Campaigns, Workers, and server-searched Runs alongside typed operator verbs (`> renew`, `> release`, `> approve`, `> reconcile`, `> wake`, `> drain`, `> cancel`), `g + <key>` navigation chords, Tier 1–3 safety rails with 1-click CLI command parity, and bulk action toolbars for Claims, Attempts, and Runs.
- Upgrade Code Review (`code-review.js`, `code-review.css`, `code_review.rs`) into a **3-pane workbench** (`16rem` sticky file+noise rail auto-collapsing to drawer in `split` mode or `<90rem`, diff with inline anchored threads, `23rem` 4-tab sticky aside), interactive `jj` stack rail, visual **Speculative Merge Train** tab, and lightweight `ci_summary` in `GET /api/code-review` list responses.
