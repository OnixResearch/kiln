# Change-local acceptance

a[define-atlas-view-note.contract] `docs/atlas-view.md` defines, before any implementation, a default-off isometric view over one caller-supplied atlas document (nodes, routes, optional chapters, optional open questions) and a packet inspector in which every payload is marked declared or observed.

a[define-atlas-view-note.qualifier] The note requires a visible qualifier in the note, any later UI, the generated prose twin and any export that declared or representative payloads are design-implied and not measured traffic, and requires observed payloads to cite exact retained evidence.

a[define-atlas-view-note.navigation] The note defines chapters and the pin list as navigation over the same document, not a second source of truth, and requires any prose twin to be generated from that document.

a[define-atlas-view-note.bounds] The note requires a later implementation to stay off by default, to refuse documents beyond named node, route, chapter, packet and hop limits, and to reuse rats issue 24 for any flat graph fallback instead of a second dependency widget.

a[define-atlas-view-note.related-work] The note records system-atlas as related work only, copies no recording frame, renderer, data module or other asset, and treats the poster's workflow claims, including the 67-pull-request anecdote, as theirs and not as evidence.

a[define-atlas-view-note.verification] Relative links resolve, no media or upstream asset is added, the documentation index links the note, and the Cairn gates and validation pass.
