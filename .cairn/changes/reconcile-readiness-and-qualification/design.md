## Decisions

Kiln maintainers own reference classification, pure adapter/parser repair, accepted-spec integration and local gate evidence. The system operator owns kernel activation, workload drain, SMT policy, resctrl mounts, exclusive CAT masks, delegation and physical-host inventory. These responsibilities are not interchangeable.

The baseline and all 98 classifications are retained; final resolutions distinguish completed-unsynced declarations, incorrect detail identifiers and obsolete unsupported administrative audit markers. Marker changes preserve real consumer obligations and runtime assertions. Historical receipts remain immutable.

Mantle ParentDir containment and feed overflow defects belong to complete-mantle-native-report and add-repository-feeds. Reproduce before fixing, retain meaningful boundary regressions, run compiled consumer smoke and integrated checks, then synchronize completed packages in dependency order with preview before mutation. This operation itself synchronizes no requirements.

Verification-only repairs bind native Nix fixture outputs by their actual names,
not query order, and remove incidental scheduler assumptions from HTTP tests.
The private HTTP shell receives its existing active counter explicitly;
production callers still initialize it to zero and preserve the admission and
release algorithm. Controlled at-bound listener tests verify rejection without
durable admission, then normal admission after release. They are not proof of
occupied handlers in the standalone binary: a separate source-bound, actual-
binary capacity probe must observe partial connections at the bound, capacity
rejection without effects, both deadline responses, and one subsequent
nonduplicate execution. Temporary probe targets are removed after observation.
No provider port, wire field, profile policy, retry rule or authority changes.

Release-readiness is a bounded local receipt, not physical-host or hostile-isolation authority. Keep actual execution, fixture scope, heavyweight checks and physical qualification distinct. Unknown or vulnerable host issue-policy status is never overridden. SMT/KSM exceptions require an actual reviewed operator decision. Do not reboot a live workstation or interrupt unrelated production services.
